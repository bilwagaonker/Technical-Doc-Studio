Creating Purchase Orders in SAP

Purpose

To create a purchase order for two line items and ensure the system pulls relevant material master data.

Procedure

Step 1

Setting Default Plant

Because in personal settings, I have already set our plant as a default plant.

Step 2

Navigating to Purchase Order Creation

Now, price enter. The system will pull the material master data.

Step 3

Creating First Line Item of Purchase Order

We have entered this first line item, we will enter second line item. Transaction: ME22N.

Step 4

Creating Second Line Item of Purchase Order

Hard disk search, find and double-click on the material master data. Transaction: ME22N.

Step 5

Entering Quantity for First Line Item

We need to enter quantity and it's okay now.

Step 6

Reviewing Purchase Order Details for First Line Item

So here we can select the required line item to see the details of that particular line.

Step 7

Reviewing Purchase Order Details for Second Line Item

Same steps will be followed for creating second line item and reviewing its details.
